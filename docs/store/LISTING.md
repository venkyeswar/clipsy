## Description
Uses the store's formatting: `**bold**`, `_italics_`, `* lists`, backticks for code.
```
Clipsy remembers everything you copy, so you can find it again in a second.

Press **Super+Shift+V** and a small, fast popup shows your clipboard history: text, links, code, rich text, images and files. Click an item to use it again.

**What you get**

* Text, images, files and rich text, with image thumbnails
* Search as you type, and filter by **Text**, **Images** or **Files**
* Pin the clips you reuse. Pinned clips are never cleaned up.
* Light and dark themes that follow your system
* Your own shortcut, history size and storage limits
* Resize and move the popup. It remembers its size.
* Can start at login and run quietly in the background

**Private by design**

Your history stays on your computer and is never sent anywhere. Copies from password managers are skipped, and you can pause recording or exclude apps at any time.

**Commands**

* `clipsy toggle` shows or hides the popup
* `clipsy settings` opens Settings
* `clipsy pause` and `clipsy resume` stop and restart recording

**Good to know**

Works on Ubuntu on Xorg (X11) today. Wayland support is coming. To use Xorg, pick _Ubuntu on Xorg_ from the gear icon on the login screen.

Source code and issues: https://github.com/venkyeswar/clipsy
```
